Proyecto Módulo 2 – Alke Wallet

La aplicación simula una billetera digital, permitiendo realizar operaciones básicas de forma simple e intuitiva.

Objetivo
Aplicar los fundamentos del desarrollo Frontend mediante la creación de una aplicación web que utilice:
- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery

Descripción general
La aplicación permite:
- Iniciar sesión en la billetera
- Visualizar un saldo disponible
- Realizar depósitos de dinero
- Enviar dinero a contactos predefinidos
- Visualizar un historial de movimientos
- Cerrar sesión
